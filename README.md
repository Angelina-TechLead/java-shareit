# ShareIt - Микросервисная архитектура

Проект разделен на два микросервиса:
- **shareit-gateway** (порт 8080) - прокси-шлюз с валидацией
- **shareit-server** (порт 9090) - основной сервер с бизнес-логикой

## Архитектура

### Gateway (порт 8080)
- Контроллеры для обработки HTTP-запросов
- Валидация входных данных
- Проксирование запросов к server
- Кэширование (планируется)

### Server (порт 9090)
- Основная бизнес-логика
- Работа с базой данных
- Без валидации входных данных

## Запуск

### Требования
- Java 21+
- Maven
- PostgreSQL (для production) или H2 (для тестов)

### Сборка и запуск

1. Собрать проект:
```bash
mvn clean install
```

2. Запустить server:
```bash
cd server
mvn spring-boot:run
```

3. Запустить gateway:
```bash
cd gateway
mvn spring-boot:run
```

### Docker Compose

Для запуска с PostgreSQL:
```bash
docker-compose up -d
```

## API Endpoints

Все запросы к API должны идти через gateway (порт 8080):

- `GET /users` - получить всех пользователей
- `POST /users` - создать пользователя
- `GET /users/{id}` - получить пользователя
- `PATCH /users/{id}` - обновить пользователя
- `DELETE /users/{id}` - удалить пользователя

- `GET /items` - получить все предметы
- `POST /items` - создать предмет
- `GET /items/{id}` - получить предмет
- `PATCH /items/{id}` - обновить предмет
- `DELETE /items/{id}` - удалить предмет
- `GET /items/search` - поиск предметов

- `GET /bookings` - получить бронирования
- `POST /bookings` - создать бронирование
- `GET /bookings/{id}` - получить бронирование

- `GET /requests` - получить запросы
- `POST /requests` - создать запрос
- `GET /requests/{id}` - получить запрос

## Валидация

Валидация происходит в gateway:
- Проверка обязательных полей
- Валидация email
- Валидация дат бронирования
- Проверка положительных значений для пагинации
